FREE PUBLISHING:
Use GitHub Pages. GitHub Pages is available with GitHub Free for public repositories.

1. Create a free GitHub account at https://github.com/
2. Create a NEW PUBLIC repository named:
   YOUR-USERNAME.github.io
   (replace YOUR-USERNAME with your GitHub username)
3. Upload index.html, robots.txt and sitemap.xml.
4. Go to repository Settings -> Pages.
5. Select the main branch as the publishing source.
6. Open:
   https://YOUR-USERNAME.github.io/

IMPORTANT:
Before publishing, replace YOUR-USERNAME in robots.txt and sitemap.xml with your real GitHub username.
In index.html, also replace YOUR-USERNAME in the LocalBusiness JSON-LD URL.
